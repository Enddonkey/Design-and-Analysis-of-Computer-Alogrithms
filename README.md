## HM1 - 分治算法

> 📄 详细题目说明请参考：`HM1/hw1.pdf`

### 1. Binary Tree（二叉树重建）
**文件**：`Binary Tree.cpp`

**问题描述**：给定二叉树的前序遍历和中序遍历，输出后序遍历。

**算法思路**：
- 利用分治思想递归构建二叉树
- 前序遍历的第一个节点是根节点
- 在中序遍历中找到根节点位置，划分左右子树
- 递归处理左右子树，最后输出根节点（后序遍历）

**时间复杂度**：O(n²)（可优化至O(n)）

---

### 2. Fast Power（快速幂）
**文件**：`Fast Power.cpp`

**问题描述**：计算 $x^k \bmod 998244353$

**算法思路**：
- 使用二进制快速幂算法
- 将指数k按二进制位分解
- 通过反复平方和条件乘法，将时间复杂度从O(k)降至O(log k)

**时间复杂度**：O(log k)

**核心公式**：
$$
x^k = \begin{cases}
(x^{k/2})^2 & \text{if } k \text{ is even} \\
x \cdot (x^{k/2})^2 & \text{if } k \text{ is odd}
\end{cases}
$$

---

### 3. Inversion（逆序对）
**文件**：`Inversion.cpp`

**问题描述**：统计数组中的逆序对数量（i < j 但 a[i] > a[j]）。

**算法思路**：
- 在归并排序过程中统计逆序对
- 当右半部分的元素被选中时，左半部分剩余的所有元素都构成逆序对
- 利用分治思想，在合并过程中累加逆序对数量

**时间复杂度**：O(n log n)

---

### 4. Maximum Subarray（最大子数组和）
**文件**：`Maximum Subarray.cpp`

**问题描述**：求数组中连续子数组的最大和。

**算法思路**：
- 使用Kadane算法（动态规划思想）
- 维护以当前位置结尾的最大子数组和
- pre = max(pre + a[i], a[i])
- 全局最优解为所有局部最优解的最大值

**时间复杂度**：O(n)

---

### 5. Nearest Pairs（最近点对）
**文件**：`Nearest Pairs.cpp`

**问题描述**：在二维平面上找到距离最近的两个点。

**算法思路**：
- 分治算法的经典应用
- 按x坐标排序后递归划分左右区域
- 分别求解左右区域的最近点对
- 合并时考虑跨越中线的点对，只需检查距离中线小于当前最小距离的点
- 使用y坐标排序优化跨中线点对的检查

**时间复杂度**：O(n log n)

## HM2 - 动态规划基础

> 📄 详细题目说明请参考：`HM2/hw2.pdf`

### 1. King Placement（国王放置）
**文件**：`King Placement.cpp`

**问题描述**：在n×n的棋盘上放置k个国王，使得没有两个国王相邻（包括对角线），求方案数。

**算法思路**：
- 状态压缩动态规划
- 用二进制表示每一行国王的放置状态
- f[i][j][state]：前i行放置j个国王，第i行状态为state的方案数
- 预处理合法状态（同一行内国王不相邻）
- 转移时检查相邻行的状态是否冲突

**时间复杂度**：O(n × k × s²)，s为合法状态数

---

### 2. Lawn Mopping（割草问题）
**文件**：`Lawn Mopping.cpp`

**问题描述**：给定数组，可以选择一段长度不超过k的连续区间，获得该区间的和，但之后不能再选择任何区间。求最大收益。

**算法思路**：
- 动态规划 + 单调队列优化
- f[i][0]：前i个位置不选择任何区间的最大收益
- f[i][1]：前i个位置选择一个区间且区间以位置i结尾的最大收益
- 使用单调队列维护区间和的最优起点，优化转移

**时间复杂度**：O(n)

---

### 3. Longest Increasing Subsequence（最长上升子序列）
**文件**：`Longest Increasing Subsequence.cpp`

**问题描述**：求序列的最长严格上升子序列的长度。

**算法思路**：
- 贪心 + 二分查找优化
- 维护tail数组，tail[i]表示长度为i的上升子序列的最小末尾元素
- 对于每个新元素，二分查找插入位置
- 如果大于所有已有元素，扩展序列长度；否则替换以保持最小性

**时间复杂度**：O(n log n)

---

### 4. Merging Stones（合并石子）
**文件**：`Merging Stones.cpp`

**问题描述**：n堆石子排成环形，每次合并相邻两堆，代价为两堆石子数之和。求最小/最大总代价。

**算法思路**：
- 区间动态规划
- 破环成链：将环复制一份接在后面，共2n堆
- f[i][j]：合并第i到第j堆的最小代价
- g[i][j]：合并第i到第j堆的最大代价
- 枚举断点k：f[i][j] = min(f[i][k] + f[k+1][j] + sum[i..j])
- 最终答案为所有长度为n的区间中的最优解

**时间复杂度**：O(n³)

---

### 5. Treasure（宝藏背包）
**文件**：`Treasure.cpp`

**问题描述**：多重背包问题，每种物品有价值v、重量w和数量m，背包容量W，求最大价值。

**算法思路**：
- 多重背包的二进制优化
- 将每种物品的m个拆分成log(m)个物品包
- 使用二进制拆分：1, 2, 4, 8, ..., 2^k, m-2^(k+1)+1
- 转化为01背包问题求解

**时间复杂度**：O(nW log m)

## HW3 - 高级数据结构

> 📄 详细题目说明请参考：`HW3/hw3.pdf`

### 1. Range Maximum Subarray（区间最大子数组和）
**文件**：`Range Maximum Subarray.cpp`

**问题描述**：给定数组，多次查询区间[l, r]内的最大子数组和。

**算法思路**：
- 线段树维护区间信息
- 每个节点维护：
  - sum：区间和
  - lmax：从左端点开始的最大子数组和
  - rmax：到右端点结束的最大子数组和
  - maxn：区间内最大子数组和
- 合并时：
  - 区间和直接相加
  - lmax = max(左.lmax, 左.sum + 右.lmax)
  - rmax = max(右.rmax, 右.sum + 左.rmax)
  - maxn = max(左.maxn, 右.maxn, 左.rmax + 右.lmax)

**时间复杂度**：建树O(n)，查询O(log n)

---

### 2. Range Update Point Query（区间修改单点查询）
**文件**：`Range Update Point Query.cpp`

**问题描述**：支持区间加操作和单点查询。

**算法思路**：
- 树状数组（差分数组）
- 区间[l, r]加k：c[l] += k, c[r+1] -= k
- 单点查询x：a[x] + sum(c[1..x])
- 利用差分思想，将区间修改转化为两次单点修改

**时间复杂度**：O(log n)

---

### 3. Range Update Range Query（区间修改区间查询）
**文件**：`Range Update Range Query.cpp`

**问题描述**：支持区间加操作和区间求和查询。

**算法思路**：
- 双树状数组
- 维护c[0][]和c[1][]两个数组
- 区间[l, r]加k时：
  - c[0][l] += k, c[0][r+1] -= k
  - c[1][l] += l*k, c[1][r+1] -= (r+1)*k
- 区间[1, x]的和 = sum[x] + (x+1)×Σc[0][i] - Σc[1][i]
- 区间[l, r]的和 = query(r) - query(l-1)

**时间复杂度**：O(log n)

---

### 4. Rectangle Area Union（矩形面积并）
**文件**：`Rectangle Area Union.cpp`

**问题描述**：给定n个矩形，求它们覆盖的总面积（重叠部分只计算一次）。

**算法思路**：
- 扫描线算法 + 线段树
- 将每个矩形分解为两个事件：下边界（+1）和上边界（-1）
- 按y坐标排序事件
- 用线段树维护当前扫描线上被覆盖的x轴长度
- 每处理一个事件，计算面积增量 = 覆盖长度 × y坐标差

**时间复杂度**：O(n log n)

## HW4 - 图论算法

> 📄 详细题目说明请参考：`HW4/hw4(1).pdf`

### 1. Disjoint Sets（并查集）
**文件**：`Disjoint Sets.cpp`

**问题描述**：支持合并操作和查询操作，输出所有查询结果按位组成的二进制数。

**算法思路**：
- 并查集（Union-Find）
- 路径压缩优化：在查找时将路径上所有节点直接连到根节点
- 按秩合并优化：将深度小的树合并到深度大的树上
- 查询操作：检查两个元素的根节点是否相同
- 结果编码：将每次查询结果（0/1）左移并累加

**时间复杂度**：接近O(α(n))，α为反阿克曼函数

---

### 2. Lowest Common Ancestor (LCA)（最近公共祖先）
**文件**：`Lowest Common Ancestor (LCA).cpp`

**问题描述**：给定树结构和根节点，多次查询两个节点的最近公共祖先。

**算法思路**：
- 倍增算法（二进制提升）
- 预处理：f[x][j]表示节点x向上走2^j步到达的祖先
- BFS求深度，同时构建倍增表
- 查询时：
  1. 先将两个节点调整到同一深度
  2. 如果相同则返回
  3. 同时向上倍增跳跃，直到跳到LCA的下一层
  4. 返回父节点

**时间复杂度**：预处理O(n log n)，查询O(log n)

---

### 3. Minimum Spanning Tree（最小生成树）
**文件**：`Minimum Spanning Tree.cpp`

**问题描述**：给定无向带权图，求最小生成树的权值和。

**算法思路**：
- Kruskal算法
- 将所有边按权值从小到大排序
- 使用并查集维护连通性
- 依次考虑每条边，如果连接的两个顶点不在同一连通块中，则加入生成树
- 重复直到选择了n-1条边

**时间复杂度**：O(m log m)

---

### 4. Shortest Path（最短路径）
**文件**：`Shortest Path.cpp`

**问题描述**：给定无向带权图，求从起点s到终点t的最短路径长度。

**算法思路**：
- Dijkstra算法（朴素实现）
- 维护dis数组表示从源点到各点的最短距离
- 每次选择未访问节点中距离最小的节点
- 用该节点更新其邻接节点的距离
- 重复直到所有节点都被访问

**时间复杂度**：O(n²)（使用优先队列可优化到O(m log n)）

## HW5 - 综合应用题

### 1. Chat Program（聊天程序优化）
**文件**：`Chat Program.cpp`

**问题描述**：有n个聊天的初始愉悦度，可以选择一段长度为m的连续区间进行优化（每个位置加上c+(j-1)×d），求选择k个聊天后的最大愉悦度总和。

**算法思路**：
- 二分答案 + 贪心验证
- 二分最终选择的第k大愉悦度值x
- 验证：统计有多少个聊天的愉悦度（可能经过优化）≥x
- 对每个可能的优化区间位置，计算优化后能达到阈值的聊天数
- 如果总数≥k，说明x可行

**时间复杂度**：O(n × m × log(max_value))

### 2. Coordinate（坐标导航）
**文件**：`Coordinate.cpp`

**问题描述**：给定一系列移动指令（U/D/L/R），通过重新排列指令顺序，使得移动过程中不经过目标点(n, m)，但最终到达该点。

**算法思路**：
- DFS + 剪枝
- 统计每个方向的移动次数
- 枚举4个方向的全排列（4! = 24种）
- 对每种排列，模拟移动过程
- 检查是否在到达终点前经过目标点
- 找到任意一个合法排列即可

**时间复杂度**：O(4! × 总移动次数)

### 3. K Co-prime Permutation（K互质排列）
**文件**：`K Co-prime Permutation.cpp`

**问题描述**：构造1到n的排列，使得gcd(i, p[i]) = 1对所有i≠k成立，且gcd(k, p[k]) > 1。

**算法思路**：
- 构造性算法
- 观察：对于i≠k，令p[i] = i满足gcd(i, i) = i > 1（不满足）
- 但如果p[k] = k，其他位置交换：p[1]=2, p[2]=3, ..., p[k]=k, ...
- 简化构造：p = [k, 1, 2, 3, ..., k-1, k+1, ..., n]
- 位置k放k（gcd(k,k)=k>1），其他位置都错位（保证互质）

**时间复杂度**：O(n)

**特殊情况**：k=0时无解

### 4. Social Media（社交媒体）
**文件**：`Social Media.cpp`

**问题描述**：n个人分为两组，给定m对关系，可以额外邀请k-n个人。最大化同一组内的关系对数。

**算法思路**：
- 贪心 + 分类讨论
- 统计已有关系：
  - 同组内的关系直接计入答案
  - 不同组的关系记录到对应节点
  - 未分配节点间的关系特殊处理
- 对于未分配的k-n个位置：
  - 考虑单独邀请某个人：获得该人的所有关系
  - 考虑邀请有连接的两个人：获得他们之间的关系和各自的其他关系
  - 取最优方案

**时间复杂度**：O(m + k)
